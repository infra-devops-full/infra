# Documentos históricos

Estes arquivos descrevem a **primeira versão** da infra, com chart e ArgoCD
específicos do crivo (Keycloak, Kong, Konga) e caminhos como `helm/crivo-app`,
`argocd/applicationsets/` e `config/secrets.*`. Essa estrutura foi substituída
pela plataforma genérica atual (`charts/app`, `argocd/` genérico e
`projects/<nome>/`).

Ficam aqui só como referência histórica. A documentação atual está em
[`docs/`](../README.md).
